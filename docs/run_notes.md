# Run Notes

This project runs an essay scoring experiment for e-commerce writing data.

## Setup

```bash
pip install -r requirements.txt
```

## Before running

- Check input data paths in `essay_scoring.py`.
- Confirm any model or tokenizer paths are available locally.
- Keep raw datasets, generated predictions, and trained model files outside Git.

## Run

```bash
python essay_scoring.py
```

## Outputs

Record dependency versions and input data revision with each run so evaluation results can be compared later.
